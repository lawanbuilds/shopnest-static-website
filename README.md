# ShopNest — Static E-Commerce Storefront

A responsive, semantic HTML5 and CSS3 e-commerce storefront built with Bootstrap 5, Flexbox, and custom CSS design tokens—designed as the UI foundation for Phase 3 React component migration.

## Key Features

- **Semantic HTML5 Architecture:** Built with `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, and `<footer>`.
- **Sticky Navigation Bar:** Brand logo, navigation links, search bar, cart item badge, and responsive mobile toggler.
- **Hero & Promotional Strip:** High-contrast hero banner with dual CTAs (`Shop Now`, `View Deals`) and a seasonal promo `<aside>`.
- **Featured Products Grid:** 6 `<article>` product cards with hover zoom, star ratings, `<del>` MRP, and discounted INR (`₹`) pricing.
- **Category Showcase & Newsletter:** 4 clickable visual category tiles, email subscription form, and a 4-column footer.

## Folder Structure

- `index.html` — Main semantic HTML5 entry point.
- `README.md` — Project overview and setup instructions.
- `.gitignore` — Git exclusion rules for OS and editor files.
- `css/style.css` — Custom CSS variables, component styles, and responsive media queries.
- `assets/images/` — Local image assets directory.

## Local Setup

1. Clone or download the repository.
2. Open `index.html` directly in any modern browser or serve via VS Code **Live Server**.
